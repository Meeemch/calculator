Калькулятор (Python)

Программа установит приложение PyCalculator в папку «Программы» и команду pycalculator для запуска из терминала.

Возможности: арифметика, %, степень, sin, cos, √, floor, ceil, память (MC, MR, M+, M−).

Приложение скомпилировано в машинный код (Nuitka) — устанавливать Python не нужно.
