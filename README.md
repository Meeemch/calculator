# Калькулятор

Учебный проект, разработанный командой из 3-х человек в рамках дисциплины **«Технологии непрерывного цикла разработки программного обеспечения»** (7 семестр, Кафедра КБ-3).

Проект демонстрирует навыки командной разработки, использования системы контроля версий Git (ветвление, слияние, разрешение конфликтов) и написания модульных тестов (unittest).

---

## Возможности

Приложение реализует полный набор функций, распределенных между участниками команды:

### Базовые арифметические операции
- Сложение (`+`), Вычитание (`−`), Умножение (`×`), Деление (`÷`)
- Остаток от деления (`%`)
- Возведение в степень (`^`)

### Математические функции
- Синус (`sin`) и Косинус (`cos`)
- Квадратный корень (`√`)
- Округление в меньшую (`floor`) и большую (`ceil`) сторону

### Дополнительные функции
- Работа с памятью: добавление (`M+`), вычитание (`M-`), очистка (`MC`), вызов (`MR`)
- Очистка текущего ввода (`C`) и удаление последнего символа (`⌫`)
- Смена знака числа (`±`)
- Валидация ввода и обработка ошибок (деление на ноль, корень из отрицательного числа)
